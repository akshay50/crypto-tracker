# Crypto Tracker

A simple React-based cryptocurrency tracker that fetches live market data and allows users to add/remove favorite coins.

## Features

✅ Displays live cryptocurrency data  
✅ Allows users to add/remove favorites  
✅ Saves favorites using Local Storage  
✅ Interactive UI with charts and icons

## Prerequisites

- Node.js (v16+ recommended)
- npm or yarn
- React.js

## Installation

### 1️⃣ Clone the Repository

```sh
git clone https://github.com/akshay50/crypto-tracker.git
cd crypto-tracker
```

### 2 Run App

npm install && npm run dev
